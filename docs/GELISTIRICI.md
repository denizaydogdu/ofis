# Ofis — developer reference (GELISTIRICI)

Read this before you change code in this repository. `CLAUDE.md` is the **CEO session's** rule set only (who talks to
it, jobs, notices, decisions, limits); it is loaded on every CEO turn, so it stays short. Everything about how the
office is built — the server, the post office, the review panel, the page, the 3D scene, the NPCs, the API fields, the
files — lives here. Split approved by the owner on 2026-11-13; the texts below were moved verbatim from `CLAUDE.md`, so in
them "you" is the CEO session.

**Keeping the two in step.** A change that alters what the CEO must do (a new notice, a new command, a new rule)
updates `CLAUDE.md` (the short rule) **and** the matching section here (the full behaviour). A change that only alters
internals updates this reference only.

## Running the tests
Everything: `python3 test/hepsi.py` — every `test/test_*.py` in parallel (workers = min(4, cpu/2), each job under
`nice -n 10`, 900 s limit per job); the slow files (`test_npc`, `test_denetci`, `test_web`, `test_ofis_plani`, …) run
as one job per TestCase class, longest first. One line per job (name, OK/FAIL/TIMEOUT, seconds), failing output at the
end, exit code 1 on any failure. `python3 test/hepsi.py npc web` = only files whose name contains a word; `-j 2` = fewer
workers. Fast mode: `--hizli` skips tests marked `@yavas` (`test/yavas.py`); `OFIS_YAVAS=1` keeps them. The default
full run includes everything — run it before a commit. One file: `nice -n 10 python3 -I test/<file>.py`; one class or
test: `python3 -I test/test_npc.py DayWalkTest[.test_four_busy_projects]` (not `-m unittest`: `test` collides with the
stdlib). The tests of `web/` (`test_web.py`, `test_komuta.py`, `test_npc.py`,
`test_bildirim.py`, …) run the JavaScript with node and are skipped without it. No browser for checks.
